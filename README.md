# Algoritmo Burrows Wheelers Transformers
### Ali El Barnaoui

Il Algoritmo Burrows Wheelers Transformers(BWT) viene usato per per la compressione dei dati senza perdita(lossless).
Non comprime direttamente ma viene usato da altri algoritmi per comprimere i file, Ad Esempio: bzip2(Sistemi Unix/Linux) oppure MTF
